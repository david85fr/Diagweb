# Diagweb

**Web diagnostic for controllers** — a web-based interface for inspecting, testing and troubleshooting controllers.

## Overview

Diagweb aims to provide a browser-accessible diagnostic tool for controllers,
making it possible to check status, read parameters and run diagnostic
routines without installing dedicated desktop software. The goal is a
lightweight, portable front end that any technician can open from a laptop,
tablet or phone on the same network as the device under test.

> ⚠️ **Early stage.** This repository is at its very beginning — the codebase
> is not yet in place. The sections below describe the intended direction and
> will be filled in as the project takes shape.

## Intended features

- Connect to a controller and display its live status.
- Read and monitor diagnostic parameters and values.
- Run diagnostic checks and surface results in the browser.
- Present logs and history in a clear, readable interface.
